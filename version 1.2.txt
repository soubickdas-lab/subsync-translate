--------------------------------------------------
 FEATURES (is version me kya kya hai)
--------------------------------------------------
1. 100% LOCAL mode — koi API nahi, koi internet nahi
   (sirf pehli baar model download hota hai)
2. Whisper large-v3 transcription (faster-whisper)
   - GPU (NVIDIA CUDA) pe auto chalta hai, warna CPU
   - Word-level timestamps
   - Models: large-v3 / large-v3-turbo / medium / small / base
3. Audio language AUTO-DETECT + 30+ language selector
4. SRT re-timing: aapke SRT ke breaks EXACTLY same rehte hain,
   sirf start/end timings audio se correct hoti hain
   - Jo line audio me na mile wo smartly interpolate hoti hai
5. Local translation: Meta NLLB-200 model — 35+ output languages
   (Hindi, Bengali, Tamil, Telugu, Japanese, Korean, ...)
6. Editable preview table — download se pehle koi bhi line edit karo
7. Downloads: translated SRT + re-timed original SRT + raw transcript
8. Video files (mp4/mkv) bhi support — audio track khud nikal leta hai
9. Koi file-size limit nahi (local hai)
10. LIVE mode (Cloudflare Tunnel): apna local server internet pe
    https://manwhadub.aipoint.online se accessible
    - start-live.bat -> server + tunnel + browser, sab ek click me
11. BIG FILE upload: 30 MB+ ki files apne aap 25 MB chunks me
    upload hoti hain — Cloudflare ki 100 MB limit ka koi issue nahi,
    kitni bhi badi file bhejo
12. One-click Windows setup:
    - start-local.bat  -> sirf local (server + browser)
    - start-live.bat   -> local + live URL (Cloudflare tunnel)
    - setup.bat        -> manual setup
    - update.bat       -> GitHub se latest version + current version dikhata hai
13. Online mode bhi available (Groq API + browser):
    https://soubickdas-lab.github.io/subsync-translate/
