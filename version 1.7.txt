 SubSync Translate — VERSION 1.7

--------------------------------------------------
 FEATURES (is version me kya kya hai)
--------------------------------------------------
1. 100% LOCAL mode — koi API nahi, koi internet nahi
   (sirf pehli baar model download hota hai)
2. Whisper large-v3 transcription (faster-whisper)
   - GPU (NVIDIA CUDA) pe auto chalta hai, warna CPU
   - Word-level timestamps
   - Models: large-v3 / large-v3-turbo / medium / small / base
3. Audio language AUTO-DETECT + 30+ language selector
4. SRT re-timing: aapke SRT ke breaks EXACTLY same rehte hain,
   sirf start/end timings audio se correct hoti hain
   - Jo line audio me na mile wo smartly interpolate hoti hai
5. Local translation: Meta NLLB-200 model — 35+ output languages
   (Hindi, Bengali, Tamil, Telugu, Japanese, Korean, ...)
6. Editable preview table — download se pehle koi bhi line edit karo
7. Downloads: translated SRT + re-timed original SRT + raw transcript
8. Video files (mp4/mkv) bhi support — audio track khud nikal leta hai
9. Koi file-size limit nahi (local hai)
10. LIVE mode (Cloudflare Tunnel): apna local server internet pe
    https://manwhadub.aipoint.online se accessible
    - start-live.bat -> server + tunnel + browser, sab ek click me
11. BIG FILE upload: 30 MB+ ki files apne aap 25 MB chunks me
    upload hoti hain — Cloudflare ki 100 MB limit ka koi issue nahi,
    kitni bhi badi file bhejo
12. One-click Windows setup:
    - start-local.bat  -> sirf local (server + browser)
    - start-live.bat   -> local + live URL (Cloudflare tunnel)
    - setup.bat        -> manual setup
    - update.bat       -> GitHub se latest version + current version dikhata hai
13. Online mode bhi available (Groq API + browser):
    https://soubickdas-lab.github.io/subsync-translate/
14. LIVE SYSTEM STATS — UI ke top-right me CPU / RAM / GPU / VRAM
    usage % har 2 second update hota hai
    (75%+ orange, 90%+ red)

15. TTS DUBBING — translated text se NAYA AUDIO + uska NAYA SRT
    (ai33.pro / OpenSpeaker API se — ElevenLabs, Minimax, Edge,
     Kokoro, FishAudio, Vbee, Cloned voices)
    - Naya SRT: same breaks, new audio ke exact timings
      (dubbed audio local whisper se re-align hota hai)
    - Voice selection 3 tarike: Saved voices (hamesha saved),
      Voice Library (output language ke hisaab se auto-fetch),
      Manual voice ID
    - Voice preview, speed control (0.5-1.5)
    - API key top-right 🔑 box me — ek baar daalo, saved rahegi
    - Credits balance display
    - Result me: audio player + dubbed audio download +
      dubbed SRT download + provider SRT link

16. SYNC VERIFY PLAYER — modern custom player (round play button,
    seek bar, time display) + REAL-TIME TABLE HIGHLIGHT:
    play karte hi jo line bol rahi hai wo neeche SRT table me
    highlight + auto-scroll hoti hai (original ya dubbed audio,
    dono ka option) — SRT aur audio ka sync wahi se verify karo
17. FILL GAPS toggle (VoxCap jaisa) — ek click me har line ka end
    agli line ke start tak extend (pehli line 0 se); dobara click =
    sab original timings par wapas (undo). Gap-filled state me SRT
    download karo to filename ke last me " gap-filled" likha aata hai

18. RE-SYNC MODE (naya tab upar) — translated SRT + uska audio do,
    bas timings audio se match hokar nayi "synced" SRT milti hai.
    Na translation hoti hai na TTS — sirf pure sync.
19. DUBBED SRT SYNC FIX — ab robust DP (edit-distance) alignment:
    fuzzy word matching, missing lines char-proportional fill,
    Hindi/Devanagari matras ka proper handling. Dubbed audio se
    SRT ab properly sync hota hai.
